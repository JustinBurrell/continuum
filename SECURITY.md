# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Continuum, please report it privately rather than opening a public GitHub issue.

**Contact:** justinburrell715@gmail.com
**Subject line:** `[SECURITY] Brief description`

Include as much detail as possible:
- Where the vulnerability exists (endpoint, component, flow)
- Steps to reproduce
- Potential impact

I will acknowledge the report within 48 hours and aim to resolve confirmed vulnerabilities promptly.

Please do not disclose the vulnerability publicly until it has been addressed.
